# 调音 Tiaoyin · 本地实时耳返

面向 **Windows 10/11 x64** 的原生桌面耳返软件：选择本地麦克风和耳机 → 调整音量/音色 → 持续监听。参考“爱调音”的输入/输出选择与监听工作流，代码及界面独立实现，不复制其商业代码、图标或素材。

**C++17 + 原生 WASAPI + Win32**。运行不需要 Python、Node、API Key、网络服务、虚拟声卡或管理员权限。没有录音上传、广告、遥测或自动下载。

> 重要：这是可构建、可测试的首个实现，不是已经通过你电脑声卡验收的商业级成品。目标周期、缓冲容量、驱动报告延迟与实测耳返延迟不是同一指标。任何软件都不能仅凭“有线”承诺所有设备零延迟。请按下方及 `docs/VALIDATION.md` 做本机验收。

## 功能

| 模块 | 已实现内容 |
|---|---|
| 本地设备 | 分别枚举输入/输出设备，显示系统默认设备，保存稳定设备 ID；缺失设备不自动替换 |
| 监听引擎 | WASAPI 事件驱动，共享低周期接口 IAudioClient3，独占格式协商与缓冲对齐 |
| 延迟控制 | 1.5 / 3 / 6 / 10 ms 目标周期，1–3 块缓冲余量，显示真实协商结果；传统共享回退明确显示 |
| 跨设备 | 输入/输出不同采样率；32-tap 窗化 sinc 多相重采样；小幅自适应时钟漂移补偿；有界队列 |
| 声道路由 | 通道 1→双耳、通道 2→双耳、前两路立体声、前两路混合；单声道输入可双耳监听 |
| 调音 | 输入增益、耳返音量、低/中/高三段 EQ、80 Hz 低切、噪声门、人声压缩、音效旁通 |
| 保护 | 默认 -18 dB 耳返音量，重启恢复上限 -12 dB，启动淡入、音量平滑、末级 ±0.95 数字限幅、紧急停止 |
| 录音 | 后台线程写入双声道 PCM16 WAV；记录处理后的耳返信号；录音故障不阻塞音频线程 |
| 诊断 | 输入/双声道输出电平，软件排队、时钟补偿、处理负荷、欠载/重同步/削波计数、文本报告 |
| 设备变更 | 系统通知提示；设备失效/超过 2 秒无音频则停止，不自动转到扬声器，不自动重连播放 |
| 交付 | 中文原生界面、DPI 支持、设置保存、CMake 工程、自动化测试、GitHub Actions Windows 便携版构建 |

**不包含：**ASIO 驱动宿主、VST 插件宿主、自动修音/变声、AI 降噪、混响、系统伴奏录制、虚拟麦克风、直播软件音频路由。噪声门不是 AI 降噪；数字限幅不是听力保护或自动防啸叫。当前处理前两路输入并映射输出前两路，其余输出通道置零。

## 获取和运行

打开本仓库 **Actions → Build and test → 成功的运行 → Artifacts → Tiaoyin-Windows-x64**，解压后双击 `Tiaoyin.exe`。构建完成情况以对应 Actions 运行结果为准；没有成功的运行时请使用下面的本机源码构建。

便携包应包含 `Tiaoyin.exe`、文档、核心测试程序及 SHA256 校验文件。程序未做商业代码签名；系统可能显示发布者未知。请仅使用自己仓库构建的产物，不要关闭系统安全保护来运行不明文件。

### 首次使用

1. **插好有线耳机，降低系统/耳机音量，避免外放。** 选择实际输入、输出，并勾选耳机确认。首次不自动开始监听。
2. 从“共享 / 3 ms / 1 块 / 通道 1→双耳”开始。点击“开始监听”，从 -18 dB 缓慢增加耳返音量。无声时先看输入电平，再检查声道路由、静音和输出设备。
3. 观察诊断。若欠载或采集不连续增加，停止后调为 6 ms 或 2 块。稳定后才试 1.5 ms 或独占；不要仅为了数字更小忽略爆音。
4. 共享模式允许其他软件播放伴奏；独占可能阻止它们发声。独占失败会提示原因，不会悄悄换成另一种模式或设备。

**快捷键：F8 开始/停止，F9 静音，Esc 紧急停止并保持静音。** 静音/输入增益/输出增益始终有效；“旁通音效”不绕过最后的安全限幅。WAV 录音包含耳返音量与静音效果，不是未经处理的原始麦克风录音。

关闭 Windows 声音属性中的“侦听此设备”；不要同时打开声卡硬件直通和软件耳返，否则可能出现双声/梳状滤波。最可控的组合是同一声卡的输入和耳机输出。蓝牙、USB 独立麦克风加另一张声卡、系统音效和驱动调度均可能增加实际延迟。

## 本机源码构建

安装 Visual Studio 2022 Build Tools，选择 **“使用 C++ 的桌面开发”**、Windows 10/11 SDK 和 CMake。安装开发工具是构建需要，最终 EXE 不要求用户安装这些工具。

在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

该命令仅针对这一次脚本进程设置执行策略，不修改全局策略。也可逐条执行：

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
.\build\Release\Tiaoyin.exe
```

Linux/macOS 可编译音频核心并运行测试，但**不包含桌面程序或 Linux 音频后端**：

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

## 设置、录音和隐私

设置位于 `%LOCALAPPDATA%\Tiaoyin\settings.ini`；默认录音目录为 `%LOCALAPPDATA%\Tiaoyin\Recordings`，每次录音可另选位置。设置不保存“自动开始”、耳机确认或未静音状态；每次打开均需手动开始。重启时输出音量上限 -12 dB，用户仍可在确认安全后自行调高。

默认不录音；点击录音并确认路径才创建 WAV。WAV 接近 RIFF 4 GB 上限时停止录音并提示，不自动占满磁盘。诊断报告包含设备 ID；对外分享前可删去。软件本身不联网，GitHub Actions/开发工具下载不属于运行时功能。
