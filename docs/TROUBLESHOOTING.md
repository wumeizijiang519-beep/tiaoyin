# 常见问题

## 完全无声

先看输入电平是否变化。无变化时检查所选麦克风、Windows 麦克风隐私中的“允许桌面应用访问”、硬件静音和输入增益。有变化但耳机无声时检查输出设备、系统音量、程序静音、耳返滑块及声道路由。噪声门过高可能截断轻声，请“恢复干声”排查。

程序只处理输入前两路，不会自动把专业声卡的第 3/4/... 路话筒映射过来。输入只有 1 路时不能选择“通道 2”。

## 独占启动失败

停止 DAW/会议/浏览器等可能占用该端点的软件；在声音设备高级属性允许独占；尝试 48 kHz、44.1 kHz，或改共享模式。部分设备的驱动不提供可用的独占格式。程序不自动改模式、改采样率或换设备，错误信息是应处理的条件，而不是通过静默回退隐藏。

共享模式优先使用 IAudioClient3；不支持时会明确显示“传统共享回退”。RAW 不受支持时显示“否”，不能据此认为系统音效已经绕过。

## 爆音、断音、延迟越来越大

先停止后把目标周期改 6/10 ms 或缓冲余量改 2/3 块。用稳定的有线设备、同一声卡输入输出、直接 USB 连接，避免高负载后台进程。对照“实际周期”而非 UI 目标数值。驱动不给低周期时，软件不能强迫硬件满足它。

软件排队通常应围绕一个范围波动，而不是持续增长。出现欠载、丢弃或重同步会在诊断计数中反映。无限增长被有界队列和重同步策略阻止，但重同步本身可能短暂可闻，不能当成稳定运行通过。

## 双声、回音或啸叫

关闭 Windows“侦听此设备”和声卡硬件 Direct Monitor，只保留一种监听方式。蓝牙可能有不可消除的传输缓冲；本软件不宣称蓝牙低延迟。耳机漏音、外放和高增益可造成声反馈；立即 Esc 停止并降低物理音量。末级数字限幅不能安全消除啸叫。

## 耳机拔下后停了，插回没有自动恢复

这是保护行为。刷新设备，确认仍选择正确的耳机，再手动开始。保存过的端点 ID 不存在时，选择框会保持未选择，而不是自动改用扬声器。

## 录音问题

WAV 是处理后的双声道 PCM16，包含耳返音量及静音，不是原始麦克风或系统伴奏录音。故障码 1：录音队列溢出；2：磁盘写入/文件错误；3：接近 RIFF 4 GB 上限。录音故障停止录音，不通过阻塞音频线程拖慢耳返。检查目录权限、剩余空间及磁盘状态，再手动重启录音。

## 如何重置设置

退出程序，备份后删除 `%LOCALAPPDATA%\Tiaoyin\settings.ini`。此操作不删除录音。新启动仍默认不监听、输出 -18 dB。设置不影响 Windows 的系统默认设备或驱动属性。

## 软件来源和权限

只运行自己仓库成功构建的便携版，并核对 SHA256。程序不需要管理员权限、账号或 API Key。源码构建需要 C++ 工具链，但运行时不需要。报告包含设备 ID，分享前可脱敏。
